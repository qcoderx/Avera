# Avera Incident Command Centre

A fixture-driven frontend for Avera, the autonomous incident intelligence and
resolution platform for digital banking.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Production build

```bash
cd frontend
npm run build
```

## Included screens

- System health and live incident feed
- Service map and suspect zones
- Ranked hypothesis board
- Ghost Test runs and traces
- Customer impact and silent-customer reveal
- Fix plan and rollback conditions
- Customer, routing, and code approvals
- Incident timeline
- Institutional memory
- Agent mascot states and contextual loading patterns

The hidden demo controller opens from the header or with the `D` key. It replays
the full incident story from the local fixture stream.
